# 潮信七日 / Seven Tides

- 类型：原创致敬包 · id `loop` · 7 天 × 3 时段（时间循环，最多重来 2 次）· 3 位角色 + 3 位配角 · 中文 / English
- 作者：ai-galgame contributors
- 许可：本目录内容以 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 发布（见 `LICENSE`）。

致敬题材：「时间循环」。南方海边浅湾县的台风周，一直重来的七天；循环的成因是原创的（一本没写完的潮信簿）。用到引擎的 `features.timeLoop`：没达到 tier ≥ 2 的结局就回到第 1 天，伏笔簿与事实表保留。创作说明见 `pack.ts` 的 `notes` 字段。

## 人物

- 主角色：符晚澜（海鸥，守灯人的孙女，不肯写潮信簿的最后一行）、叶棠（狐狸，凉茶铺的孙女，瞒着录取信）、陈渡（水獭，想接下阿爸的渔船）。
- 配角（1.1 新增，都有像素立绘）：姑妈（鹦鹉，开杂货铺，全县消息先到她柜台）、陈阿爸（戴斗笠的螃蟹，要卖船供女儿读书）、叶阿嬷（寄居蟹，早就知道录取信的事）。
- 关系：匿名点歌条、父女与一条船、阿嬷等孙女开口、姑妈与符伯的灯油、灯与船等 7 条。

## 结构

- 三幕：风还很远（第 1–3 天）→ 夜市与预警（第 4–5 天）→ 封港（第 6–7 天），共 8 个关键事件。时间循环回到第 1 天时关键事件会重新发生（每一轮要写出不同）；随机事件按轮次重掷，每一轮的小事不一样。
- 三个关键约定：第 5 天夜里陪阿渡等船、截止前陪叶棠去跟阿嬷说实话、第七夜陪晚澜写完最后一行；分别是三人真结局的条件。
- 7 个随机事件：骤雨、渡轮晚点、鱼价、天线被吹歪、老机器、给灯塔送凉茶、台风提前。
- 14 个结局：每人真 / 好 / 普通 / 坏，外加「又一个第一天」和兜底结局。tier ≥ 2 的结局才能打破循环。

## English

Homage to the time-loop genre using `features.timeLoop`; all content is original.

- Romanceable: Fu Wanlan (seagull), Ye Tang (fox), Chen Du (otter). Supporting (new in 1.1, with sprites): Auntie (parrot), Old Chen (crab in a bamboo hat), Grandma Ye (hermit crab). Seven relations.
- Three acts with eight key events that replay each loop; random incidents reroll per loop; three key promises gate the true endings; fourteen endings, and only tier ≥ 2 endings break the loop.
