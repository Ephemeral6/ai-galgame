# Code of conduct / 行为准则

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text at that link applies; this page adds what is specific to a story project.

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)，以该链接全文为准；下面只补充剧本项目特有的部分。

## In short / 简要

- Be kind and assume good faith; critique the writing, not the writer. / 友善，默认对方出于善意；评论作品，不评论人。
- No harassment, slurs, sexualised remarks or personal attacks, in any language. / 任何语言都不允许骚扰、侮辱、性暗示或人身攻击。
- No sexual content involving anyone under 18, in packs, issues, discussions or screenshots. / 剧本包、issue、讨论和截图里都不得出现涉及未满 18 岁者的性内容。
- Don't post other people's copyrighted work; follow the license rules in [CONTRIBUTING.md](CONTRIBUTING.md). / 不发布他人受版权保护的作品；遵守 CONTRIBUTING 里的许可规则。
- Don't share other people's private information. / 不公开他人的隐私信息。

## Enforcement / 执行

Report problems privately to the maintainers through GitHub (Security → Report a vulnerability also reaches us) or by contacting a maintainer listed on the repository. Maintainers may edit or remove content and warn, suspend or ban participants, following the Covenant's enforcement guidelines.

请通过 GitHub 私下联系维护者（Security → Report a vulnerability 也能送达）。维护者可按 Covenant 的执行指引编辑或删除内容，并警告、暂停或禁止参与者。
